Cais

Instalar o Cais

Para quem já comprou. Você precisa do código que chegou no e-mail da compra, no formato CAIS-XXXXX-XXXXX-XXXXX.

1. Digite o código da compra

2. Cole este comando no Terminal

Abra o Terminal (⌘Espaço, digite Terminal, Enter), cole o comando e aperte Enter.

O comando baixa a versão atual, abre o pacote com o seu código, põe o Cais em Aplicativos e abre. Se já houver um Cais instalado, o antigo vai para a Lixeira. O texto do instalador é aberto, para quem quiser ler antes.

Prefere não usar o Terminal?

  1. Baixe o Cais.dmg e abra. A senha do arquivo é o código da compra.
  2. Arraste o Cais para a pasta Aplicativos e abra.
  3. O macOS vai avisar que não conseguiu verificar o app. Clique em "OK", abra Ajustes do Sistema, vá em Privacidade e Segurança e clique em "Abrir Mesmo Assim" ao lado do Cais.
  4. Em Ajustes do Cais, página Sobre o Cais, digite o código da compra para receber as atualizações.

Esse aviso aparece porque o Cais não passou pela notarização da Apple, que exige uma conta paga de desenvolvedor. Pelo comando do Terminal ele não aparece.

Depois de abrir

O Cais mostra o que cada permissão liga e pede uma de cada vez. As atualizações chegam sozinhas: quando sair versão nova, aparece um aviso com o botão "Instalar e reiniciar".

Algo não funcionou? Fale com o suporte.
